# Support

## Questions and integration help

Use the repository's GitHub Discussions for usage questions, integration guidance, and ideas that
are not yet concrete feature proposals. Search existing documentation and discussions first, and
include the target platform, SDK revision, relevant configuration, and a minimal example.

## Bugs and feature requests

Open a GitHub issue for a reproducible defect or a specific feature proposal. Use the provided issue
form and include the requested environment, reproduction, expected behavior, and impact details.
Do not post credentials, private model URLs, proprietary audio, or other sensitive data.

Security vulnerabilities do not belong in issues or discussions. Follow [`SECURITY.md`](SECURITY.md)
to report them privately.

## Expectations

Support is provided by maintainers and contributors on a best-effort basis. Response times and fixes
are not guaranteed. Maintainers may close requests that cannot be reproduced, fall outside the
project's scope, or lack enough information to investigate.
