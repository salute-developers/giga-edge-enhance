Configuration and processing

Prepare the denoiser, DSP chain, and echo canceller before a real-time callback. The callback passes mono PCM through contexts that already exist.

Denoiser​

Denoiser loads a noise-suppression model from a YAML file, a YAML string, or a PackedModelReader. Copy construction is disabled. Move the object, or create it in the place that owns it for the session.

CreateContext(input_rate, output_rate) starts one stream. Pass the rates of the buffers you supply. 0, 0 means those buffers are already at feature_params.sampling_freq and the resampler stays off. Any other pair is resampled to and from the model rate. One denoiser can own many contexts. Process each context on its own stream; concurrent ProcessChunk calls use different contexts.

ProcessChunk accepts mono float in [-1, 1] or mono int16_t. GetFinalChunk flushes the overlap-add tail and replaces the output vector. DestroyContext takes a pointer to the context pointer and clears it. Destroy every context before the denoiser.

GetModelSampleRate and GetModelInputFrameSize report the model contract. GetModelInputFrameSize is the hop, in samples, at the model rate. ReloadConfig rebuilds the feature extractor and inference runner from the current configuration. Call it outside the real-time callback.

Model YAML​

A model file has three sections. The shipped 48 kHz discriminative ONNX config is models/quality48/onnx/config.yaml:

model:
  model_path: model.onnx
feature_params:
  sampling_freq: 48000
  frame_size_ms: 32
  frame_stride_ms: 16
  window_type: hanning
inference:
  gpu: false
  engine_num_threads: 1
  model_type: denoiser_discr_web_model

model_path is resolved next to the configuration file. window_type is hanning or hamming. model_type is one of:

Modelmodel_typeEngines
8 kHz quantizeddenoiser_discr_hq_modelONNX
Discriminative 48 kHzdenoiser_discr_web_modelONNX and TFLite
Hybrid 48 kHzdenoiser_hybrid_web_modelONNX and TFLite

The 8 kHz quantized config sets sampling_freq: 8000 and may set skip_zeroed_chunks: true. The hybrid configs are in models/hybrid48/onnx/ and models/hybrid48/tflite/. The roles and package ids are in Models.

Packed models​

A .enhance file is a little-endian package: uint32 configuration size, YAML bytes, uint32 model size, then the model bytes. The file ends at the model payload. PackedModelReader accepts a path or a memory buffer and exposes config() and model(). Pass std::make_shared<PackedModelReader>(...) to Denoiser.

Return codes​

GigaEdgeEnhanceRetCode is an unscoped enum. SUCCESS is 0. Check code < SUCCESS in C and code < GigaEdgeEnhanceRetCode::SUCCESS in C++.

CONTEXT_ACCUMULATION (1), RESAMPLING_INPUT_BUFFER_ACCUMULATION (2), and RESAMPLING_OUTPUT_BUFFER_ACCUMULATION (3) mean the call succeeded and the output may be empty while the model or a resampler fills its window. Negative values are failures, including a bad configuration path, a model that the selected engine cannot start, an allocation failure, and a resample or inference error. The names are in enhance/errors.h.

C API ownership​

GigaEdgeEnhanceDenoiseInit and GigaEdgeEnhanceDenoiseCreateContext write handles through pointer arguments. GigaEdgeEnhanceDenoiseProcessChunkFp and GigaEdgeEnhanceDenoiseGetFinalChunkFp allocate the output buffer. output_size is a byte count. free that buffer after every call, including a call that returns an accumulation code. GigaEdgeEnhanceDenoiseDestroyContext runs before GigaEdgeEnhanceDenoiseFree. The Int variants convert PCM16 and follow the same ownership.

Normalization​

AudioProcessor runs the DSP chain. The default constructor uses built-in settings. A YAML path or YAML string reads sound_processing:

  • loudness_ctrl — target loudness in LUFS, maximum gain, bypass time, speech detection (use_vad), and an optional built-in compressor and limiter (post_processing)
  • range_ctrl — leveler attack, hold, and release
  • auto_gain_ctrl — target level and rise/fall steps
  • noise_gate_ctrl — threshold and envelope times
  • dynamic_range_compressor_ctrl — threshold, ratio, knee, and envelope times
  • limiter_ctrl — threshold, knee, and envelope times

For example, configure loudness control with VAD for a 48 kHz speech stream:

sound_processing:
  loudness_ctrl:
    sample_rate: 48000
    target_level_db: -23.0
    bypass_time: 3.0
    max_gain_db: 12.0
    use_vad: true
    post_processing: false

Construct AudioProcessor from this YAML and call AddLC() to add the configured stage. Create the chain before the audio callback and match the module sample rates to the input. AudioProcessor::ProcessChunk writes the processed block and returns SUCCESS when processing completes. See the normalization guide for module order and streaming examples.

Acoustic echo cancellation​

EchoCanceller is available in the native SDK. Construct it from YAML. The echo_cancellation section sets sample_rate, filter_len, chunk_len_ms, residual_echo_suppression_enabled, delay_compensator_enabled, and type. The supported type value in the current configuration is speex.

Pass the microphone and the far-end loopback as two mono float vectors, or pass one interleaved chunk. See the AEC guide for frame sizing and an example pipeline, and the capability matrix for SDK support.
