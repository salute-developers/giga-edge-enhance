GigaDenoiser

GigaDenoiser is a cross-platform SDK for real-time speech enhancement. It combines neural noise suppression with DSP for native, mobile, and web applications.

The repository includes the C and C++ engine, WebAssembly integration, Android and iOS SDKs, command-line tools, demos, tests, and release packaging. The interactive demo and rendered documentation are available on the repository's GitHub Pages.

Build and test​

Git LFS is required for repository-managed models and test assets. Docker provides the default toolchain for native Linux, WebAssembly, Web, and Android builds; Apple and Windows targets use their host toolchains.

git lfs install
git lfs checkout

tools/build native-debug-onnx
tools/test native-debug-onnx

Use the repository's tools commands for supported builds, tests, installation, and packaging. Build outputs are written under out/.
