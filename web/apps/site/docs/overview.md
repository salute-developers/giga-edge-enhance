# GigaEdge Enhance documentation

GigaEdge Enhance is a cross-platform speech-enhancement SDK. Noise suppression and
normalization are available on every SDK. Acoustic echo cancellation is available
in the native and Web SDKs. The [capability matrix](capabilities.md) lists the
models and features for each platform.

## Choose your platform

- [Core C and C++ SDK](/docs/core/) for native applications and direct buffer processing.
- [Web SDK](/docs/web-sdk/) for Web Audio, AudioWorklet, and WebAssembly integration.
- [Android SDK](/docs/android/) for Kotlin/JNI applications.
- [iOS SDK](/docs/ios/) for AVAudioEngine and direct Swift buffer processing.

## Before you begin

[Getting started](getting-started.md) selects a release package and the first call for each SDK.
Repository contributors restore model and test assets through Git LFS before building from source.
