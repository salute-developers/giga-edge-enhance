# Models

Three noise-suppression models have distinct roles. The packaged identifiers stay
stable for existing SDK calls. Use the descriptive names below when choosing one.

| Name | Package id | `model_type` | Weights in this repository |
| --- | --- | --- | --- |
| 8 kHz quantized | `fast8` | `denoiser_discr_hq_model` | ONNX, `models/fast8/onnx/` |
| Discriminative 48 kHz | `quality48` | `denoiser_discr_web_model` | ONNX and TFLite, `models/quality48/` |
| Hybrid 48 kHz | Not packaged | `denoiser_hybrid_web_model` | Runner only; no trained weights |

## 8 kHz quantized

This is a quantized model for telephony and other narrowband streams. It is the
fast CPU inference option for servers: create one context per audio stream and
process those contexts concurrently. Its native rate is 8 kHz. Streams at other
rates go through the built-in resampler.

The ONNX file and `models/fast8/onnx/config.yaml` are in the repository. iOS and
the Web SDK also ship it as the packed `fast8` model. Android does not currently
package this model. TensorFlow Lite builds do not include its runner.

## Discriminative 48 kHz

This is an FP32 discriminative model for general speech enhancement. Its native
rate is 48 kHz, and the resampler accepts other stream rates. The Web SDK uses it
as the default quality choice, but native ONNX, native TFLite, Android, and iOS
can load the same model.

The repository copies are `models/quality48/onnx/` and `models/quality48/tflite/`.
Packed platform builds publish it as `quality48`.

## Hybrid 48 kHz

The hybrid model is FP32 and combines a discriminative stage with a generative
stage. It is intended to provide higher quality than the discriminative 48 kHz
model. ONNX Runtime and TensorFlow Lite both have a hybrid runner, selected with
`inference.model_type: denoiser_hybrid_web_model`.

No trained hybrid weights are shipped. `hybrid_identity.onnx` and
`hybrid_identity.tflite` under `core/tests/data/models/` are synthetic fixtures
generated by `core/tests/generate_hybrid_fixtures.py`; they only check the tensor
contract.

A hybrid model consumes a complex spectrum in `[1, frequency, time, 2]` order,
followed by eight recurrent state tensors, and returns those states plus the
enhanced spectrum. Only the spectrum time dimension may be dynamic. TensorFlow
Lite uses the `noisy_ri_in`, `prev_*_in`, `cur_*_out`, and `predicted_ri_out`
signature names.

## Platform packages

- Native applications pass a YAML config or a packed `.ges` model.
- Android discovers packaged models with `Models.available(context)`. The shipped
  module is `quality48`.
- iOS discovers `fast8` and `quality48` through `ModelCatalog`.
- The Web SDK embeds `fast8.ges` and `quality48.ges`. A packed model you supply
  uses the `custom` key.

Load and validate a model before real-time processing begins.

## Configuration values

Set `inference.model_type` to one of the values in the table above.

Contributors restore the Git LFS model and test assets with `git lfs checkout`.
Do not commit credentials, private storage URLs, or model binaries outside the
repository LFS rules.
