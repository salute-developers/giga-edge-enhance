# Android SDK

The Android SDK exposes Kotlin settings, features, model discovery, telemetry, and lifecycle APIs
over a thin JNI bridge. Applications process mono `FloatArray` buffers while the native worker owns
the real-time pipeline.

The platform documentation covers model AARs, threading, ProGuard/R8, telemetry, the demo app, and
common integration failures.
