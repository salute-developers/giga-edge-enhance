# Security Policy

## Supported versions

Security fixes are provided for the latest published GigaDenoiser release. Upgrade to
the latest release before reporting an issue that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it through
[GitHub Private Vulnerability Reporting](https://github.com/salute-developers/gigadenoiser/security/advisories/new)
with reproduction steps, affected versions, and the potential impact.

Please avoid sharing sensitive data or testing against systems you do not own.
The maintainers will coordinate disclosure through the private advisory.
